# === Experiment 1: feature causality on the cost-of-effort / replanning axis ===
# vectors/effort_L26 = SAE decoder columns of the Stage-1 decision-token features

# ones it ENHANCES (engage with the error, list the next fix). cos with tedium = +0.02,
# i.e. a different axis from the one that decoupled from prompting.
#   ablate on baseline -> does removing the replanning axis reproduce the protection?
#   add on prompt      -> the tug-of-war, this time on the right axis
