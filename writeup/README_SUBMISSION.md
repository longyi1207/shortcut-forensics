# How to submit

**Deadline:** Fri 2026-09-04 23:59 PT. Extension to Sept 11: https://forms.gle/gpceDYrxTUaZBoHA8
**Form:** https://airtable.com/appnMboxg76F1QIDc/pagqu7wWWrUCZkNVI/form

## 1. Make the Google Doc

1. Open `MATS_SUBMISSION.html` in a browser (it should have opened already).
2. Select all (Cmd-A), copy (Cmd-C).
3. New Google Doc, paste (Cmd-V). Headings, bold, the table and all four figures come across in one
   paste, because the images are embedded in the file.
4. Check the four figures landed, then set Share to "Anyone with the link can view".

The first two pages are the executive summary, which is what the form's checkbox asks about.

## 2. Fill the form

Answers are in `FORM_ANSWERS.md`, one per question, in the order the form asks them. He reads these
before the doc and uses them as the filter, so they matter as much as the write-up.

Also required: name, email, resume upload, LinkedIn, whether you can join the research phase full-time
(Jan 19 to Apr 10), the doc URL, and the two checkboxes (first 1-3 pages are an executive summary;
link sharing is on).

Optional field for code: https://github.com/longyi1207/shortcut-forensics

## 3. Before you send

- Fill in `TIMELOG.md` with your own estimate. He encourages attaching a time-tracking screenshot.
- Read the LLM-use answer in `FORM_ANSWERS.md` and make sure it matches how you'd describe it.
